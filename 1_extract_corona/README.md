# 1_extract_corona

Извлечение статей по ключевым словам `coronavirus` / `chinese virus` и формирование двух подкорпусов.

## Что делает скрипт

- Монтирует Google Диск (для работы в Colab)
- Распаковывает архив `archive.zip`
- Ищет CSV-файл и фильтрует строки начиная с 2019-12-01
- Оставляет статьи, содержащие `coronavirus` или `chinese virus`
- Очищает текст (удаляет HTML, ссылки, рекламные маркеры, «грязные» символы)
- Исключает слишком короткие тексты (менее 200 символов)
- Разделяет на два подкорпуса:
  - `coronavirus` – статьи только с этим словом
  - `chinese virus` – статьи с этой фразой
- Выводит статистику (количество статей, токенов) и топ‑10 изданий
- Сохраняет результаты в `.txt` (один файл на подкорпус, статьи через `\n\n`) и `.csv`

## Как запустить

1. Поместите `archive.zip` на ваш Google Диск (в корень или измените переменную `zip_path` в скрипте).
2. Откройте скрипт в [Google Colab](https://colab.research.google.com) или локально (удалив строки с `drive.mount` и указав свой путь к архиву).
3. Запустите все ячейки (или выполните скрипт целиком).
4. Результаты появятся в текущей папке.

## Входные данные

- Исходный корпус All the News в виде CSV-файла, упакованного в `archive.zip`.  
  Ссылка для скачивания указана в главном `README.md` корневого каталога.

## Выходные данные

| Файл | Описание |
|------|----------|
| `corpus_coronavirus.txt` | Тексты статей подкорпуса «coronavirus» |
| `corpus_chinese_virus.txt` | Тексты статей подкорпуса «chinese virus» |
| `coronavirus_subcorpus.csv` | Таблица с колонками `date`, `publication` (если есть), `clean_article` |
| `chinese_virus_subcorpus.csv` | То же для второго подкорпуса |

## Примечания

- Скрипт оптимизирован для **Google Colab**. Для локального запуска требуется изменить путь к архиву и убрать `drive.mount`.
- Размер исходного архива ~8 ГБ, поэтому обработка идёт по частям (чанкам), что экономит память.
- Если в данных нет колонки `publication`, скрипт продолжает работу без неё.
