# 3_sentiment

Сентимент-анализ подкорпусов и ключевых коллокатов с помощью VADER.

## Что делает скрипт

- Загружает подкорпуса из CSV-файлов (`coronavirus_subcorpus.csv`, `chinese_virus_subcorpus.csv`), созданных на первом этапе.
- Для каждой статьи вычисляет **compound score** (от -1 до 1) с помощью VADER.
- Выводит среднее, медиану, стандартное отклонение и интерпретацию (позитивный/негативный/нейтральный).
- Анализирует тональность заранее заданных коллокатов (списки внутри скрипта).
- Выводит таблицу с compound, pos, neg для каждого коллоката и средний compound по списку.

## Как запустить

1. Поместите файлы `coronavirus_subcorpus.csv` и `chinese_virus_subcorpus.csv` в папку `3_sentiment/`.
2. Убедитесь, что там же лежит `sentiment_analysis.py`.
3. Запустите скрипт:
   ```bash
   python sentiment_analysis.py
