# 2_extract_collocates

Извлечение коллокатов для терминов `coronavirus` и `chinese virus` с помощью меры **logDice**. Размер окна – 5 слов слева и 5 справа.

## Что делает скрипт

- Загружает подкорпуса из CSV-файлов (`coronavirus_subcorpus.csv`, `chinese_virus_subcorpus.csv`), созданных на первом этапе.
- Очищает тексты (приводит к нижнему регистру, удаляет всё кроме букв и пробелов).
- Загружает стоп-слова из `stopwords.txt`.
- Находит все вхождения целевой фразы:
  - `coronavirus` (одно слово)
  - `chinese virus` (биграмма)
- В скользящем окне (5 слов слева, 5 справа) собирает слова-коллокаты.
- Вычисляет **logDice** по формуле:  
  `logDice = 14 + log2(2*O / (C + R_total))`,  
  где `O` – частота коллоката в окне, `C` – общая частота коллоката, `R_total` – число вхождений целевой фразы.
- Отбирает топ‑20 коллокатов для каждого подкорпуса и выводит их в консоль.

## Как запустить

1. Поместите файлы `coronavirus_subcorpus.csv` и `chinese_virus_subcorpus.csv` в папку `2_extract_collocates/`.
2. Убедитесь, что там же лежат `collocates_extract.py` и `stopwords.txt`.
3. Запустите скрипт:
   ```bash
   python collocates_extract.py
